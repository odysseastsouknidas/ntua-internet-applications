# MovieLens Web Application

This project is a web application for the ECE NTUA Internet Applications course.

The application is based on the MovieLens Latest Small dataset and supports:

- searching movies by keyword
- searching movies by tag
- adding new movies
- viewing average movie ratings
- storing user ratings in browser memory during the session
- requesting personalized movie recommendations

## Project Structure

- `frontend/`: HTML, CSS, and vanilla JavaScript frontend
- `backend/`: FastAPI backend and database setup
- `docs/`: assignment descriptions
